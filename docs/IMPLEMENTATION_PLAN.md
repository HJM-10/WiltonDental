# Wilton Dental redevelopment

Baseline: commit `62fc513`. Existing static output and Vercel deployment structure retained. Previous homepage also copied to `tmp/baseline/index.html` before changes.

## Acceptance sequence

1. Inventory the public practice pages, original logo, service imagery and all six team members. Record sources and content gaps.
2. Introduce a repeatable static build with shared navigation, styling and real page URLs. Preserve direct call, email and WhatsApp destinations; never show a false booking confirmation.
3. Restore every service and team member with dedicated pages, clear treatment information, authentic imagery and reliable location information.
4. Apply restrained motion without clipped text, scroll hijacking, custom cursors or forced loading sequences. Test reduced motion and JavaScript-disabled reading.
5. Add a lightweight local GLB tooth, loaded near the viewport with a static fallback, accessible controls and offscreen suspension.
6. Check navigation, content, images, responsive layouts and interactions; produce an A4 documentation report with evidence, screenshots, limitations and an operational handover.

## Content policy

Do not invent staff qualifications, reviews, opening hours, fees, guaranteed outcomes or current NHS availability. Published seasonal offers are not evergreen prices. Distinguish the illustrative tooth from diagnostic imaging. Record incomplete source biographies and conflicting contact details in the report.
